    Drake v1.59.0

    Back to Release Notes

    Announcements

    • MultibodyPlant now models closed kinematic loops automatically by default (#25250).
      • Users can opt-out with the new MultibodyPlantConfig::enable_loop_topology option or with plant.SetEnableLoopTopology(false).
    • Drake now officially supports macOS 27 Golden Gate (#25156).
    • Drake now uses x86-64-v2 as the minimum target microarchitecture on x86-64 (#25051).
    • Drake’s manylinux pip wheels now support Python 3.15 (#25219)
    • Drake now offers a build option DRAKE_TEXT_LOGGING for opting-out of spdlog in order to log directly to stderr (#25152).
      • This splits out the Bazel flag for “use spdlog” vs “which spdlog” (dropping the experimental “disabled” option).
      • Wheel (pip) builds use the opt-out while still routing logs to Python’s built-in logging module.

    Breaking changes since v1.58.0

    • When installing Drake via pip, users who need MosekSolver must now opt-in to the [mosek] extra to request installing Drake with MOSEK support (#25220).
    • MultibodyPlantConfig.use_sample_output_ports has changed its type to a std::variant (#25218).
      • The setting is no longer ignored for a continuous-time plant. Instead, the Unchanged option (the new default) can be used to indicate that the plant setting should be left alone.
      • Users with a config file that previously set both time_step: 0 and use_sampled_output_ports: true should change the true to either false or !Unchanged {}.
    • Implementations of planning::DistanceAndInterpolationProvider must implement the new method DoComputeConfigurationDeltas; no default implementation is provided (#25115).
      • See //planning/linear_distance_and_interpolation_provider.cc for an example implementation of the new method.
    • When using NloptSolver, exceptions thrown by costs and constraints were previously swallowed but are now rethrown from Solve() with their message, matching SnoptSolver (#25079).

    Refer to our Drake Stability Guidelines for our policy on API changes.

    New features

    • Enable automatic loop topology modeling by default (#25250)
    • CENIC can report ICF forces from a continuous plant via sampled output ports (#25147)

    Fixes

    • Streamline collision filtering for anchored geometry pairs (#25150)
    • Keep half spaces from breaking FCL tree rebalancing (#25188)
    • Fix touching box-box gradients (#25182)
    • Fix undefined behavior in CalcJacobianSpatialVelocity with no degrees of freedom (#25131)
    • Give the ICF reaction-force ladder finite axial inertia (#25263)
    • Fix SapConstraint::ToDouble() for reduced constraints (#25146)
    • MinimumDistanceLowerBoundConstraint and MinimumDistanceUpperBoundConstraint apply q’s gradient just once, for performance (#25107)
    • Make MultibodyPlant::SetVelocitiesInArray preconditions check consistent with similar methods (#25110)
    • Parsing preserves poses of SDFormat frames attached to joints or later frames (#25095)
    • Parsing puts each SDFormat frame in the model instance that declares it (#25123)
    • Parsing fixed and extends frame references in SDFormat drake: tags (#25132)
    • Parsing fixed dangling pointer in SDFormat reposture callback (#25239)
    • Parsing no longer treats warnings from SDFormat-included URDF as errors (#25251)
