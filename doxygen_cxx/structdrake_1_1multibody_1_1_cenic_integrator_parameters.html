CenicIntegratorParameters Struct Reference

Detailed Description

(Advanced) Parameters to configure a CenicIntegrator.

These are the CENIC-specific settings that can be given to a Simulator via drake::systems::SimulatorConfig::integrator_params. In YAML, they are selected with the !CenicIntegratorParameters tag. For example:

integration_scheme: cenic
integrator_params: !CenicIntegratorParameters
explicit_external_inputs: true
icf_solver:
min_tolerance: 1e-6

These are the settings that belong to CENIC itself, as opposed to the ICF solver it uses (which are in icf_solver).

◆ explicit_external_inputs

bool explicit_external_inputs {false}

Whether to treat the plant's external inputs (actuation and external forces) explicitly, i.e., hold them fixed at their values at the start of the step.

When false (the default), they are linearized with respect to velocity using finite differences so that they can be treated implicitly, which requires re-evaluating all upstream systems several times per step. Setting this to true skips that work, which is useful when the inputs come from expensive external systems, at the cost of reduced stability for stiff feedback controllers. This option can be used with or without error control. See also Explicit external inputs.
